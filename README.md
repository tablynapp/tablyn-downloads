# Tablyn

Tablyn is an offline Windows application for building and automatically solving school timetables.

## Download

Download the latest Windows installer from the repository's **Releases** page.

The evaluation version can build, solve, and preview a timetable. A Tablyn license is required to print, save, or export protected output.

## System requirements

- Windows 10 or Windows 11, 64-bit
- No internet connection is required after installation

## Current release

Tablyn 1.2.1

## Verify the installer

The SHA-256 checksum is published beside every release. In PowerShell, run:

```powershell
Get-FileHash .\Tablyn-Setup.exe -Algorithm SHA256
```
