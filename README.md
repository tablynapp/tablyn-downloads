# TablynTablyn is an offline Windows application for building and automatically solving school timetables.## DownloadDownload the latest Windows installer from the repository's **Releases** page.The evaluation version can build, solve, and preview a timetable. A Tablyn license is required to print, save, or export protected output.## System requirements- Windows 10 or Windows 11, 64-bit- No internet connection is required after installation## Current releaseTablyn 1.2.2## Verify the installerThe SHA-256 checksum is published beside every release.
